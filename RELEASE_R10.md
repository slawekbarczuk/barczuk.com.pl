# SB-WEB-1126-R10

Zaakceptowany wariant A propozycji P02 z 17 listopada 2026 r. Strona główna przedstawia specjalizację w finansowaniu przedsiębiorstw i inwestycji, cztery etapy doradztwa oraz rozbudowane opisy sposobu pracy i współpracy. Nowa podstrona `/finansowanie-przedsiebiorstw/` zawiera sześć zakresów doradztwa.

Samodzielne oferty prawa, zarządzania i IT zostały wycofane. Dawny adres oferty finansowej przekierowuje na nową podstronę. Pozostałe wycofane strony zwracają stronę błędu z odnośnikiem do aktualnej oferty.

Zachowano produkcyjny formularz P04 zamiast formularza demonstracyjnego. Jego pola, ograniczenia, pułapka antyspamowa, adresy API i skrypt obsługi pozostają niezmienione. Kod API, mechanizm limitowania, zależności i istniejące procesy publikacji są niezmienione. Nie modyfikowano ustawień Azure, Cloudflare ani Microsoft Graph. Zachowano treść informacji prawnych, prywatności i cookies oraz istniejącą analitykę.

Weryfikacja przed publikacją obejmuje testy API i limitowania oraz kontrolę zachowania P04, treści prawnych, metadanych, mapy witryny i wycofanych adresów. Migawka R09, potwierdzenie gotowości API przed aktualizacją, materiały odbiorowe i końcowy raport publikacji są przechowywane w archiwum projektu poza publicznym serwisem.
